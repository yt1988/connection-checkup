# Connection Checkup

One run that chains the 1ms.dog network tools (Who Are You, IP Quality, EgressLens, Unlock, IPv6, DNS, Speed, service latency) into one graded report, with a shareable link and card. Work in progress: see `src/tools.mjs`, `src/report.mjs`, `src/share.mjs` and `test/fixtures/`.

**Live (planned):** https://check.1ms.dog
