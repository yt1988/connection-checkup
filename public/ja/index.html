                        ヘルプ

                        ネットワーク透視では何がわかりますか？

                        このページで 1ms.dog の 8 つのツールを順番に動かし、結果を 1 つのレポートにまとめます。あなたは誰（サイトから何が見えるか）、IP 品質テスト、出口照魔鏡（各サイトから見える出口 IP）、IPv6 テスト、DNS テスト、動画配信/AI 解除チェック、1ms.dog トップのサービス遅延テスト、スピードテストです。

                        各ツールは小さな窓の中で動き、それぞれ進み具合と結果を表示してから、数値をこのページに渡します。測り直しも簡略化もしていません。ここの数値は各ツールが表示する数値と同じです。

                        なぜ 3 段階で、約 90 秒かかるのですか？

                        速度テストは回線の帯域を使い切るため、遅延や DNS の測定を狂わせてしまいます。そこで最後に単独で行います。ステップ 1 で身元・IP・出口・IPv6・DNS を同時に、ステップ 2 で動画配信・AI の利用可否と遅延を、ステップ 3 で速度を測ります。

                        各ステップは、ツールから結果が届くまで最長 90 秒待ちます。それまでに届かなかったツールは「未完了」として評価から外します。

                        評価はどのように決まりますか？

                        レポートは 5 つの項目に分かれ、それぞれ A+〜F で評価します。比重は IP 品質 25%、動画配信・AI 20%、速度 20%、身元とプライバシー 20%、接続性（IPv6、DNS、サービスまでの遅延）15% です。総合評価は、完了した項目の加重平均です。完了しなかった項目は含めず、その旨をレポートに書きます。

                        もともと評価を出すツール（IP 品質、IPv6）はその評価をそのまま使います。ほかの項目は測定結果から採点します。使えるサービスの数、ダウンロードの速さ、回線が混んだときの遅延の伸び、情報漏れや矛盾の有無、DNS とサービスの速さです。

                        「組み合わせてわかったこと」とは何ですか？

                        いくつかのツールの結果を並べて初めてわかる問題です。たとえば、データセンターの IP なのにタイムゾーンが別の国でプロキシだと見抜かれる、出口が制限地域にあって AI サービスがすべて使えない、分流で AI と動画配信が別の国から出ている、DNS サーバーと出口 IP の場所が違う、ダウンロード中に遅延が跳ね上がる、などです。レポートのいちばん上に表示します。

                        データはどこかに送られますか？

                        各ツールは単体で使うときと同じく、ブラウザの中で動きます。このページは、ブラウザ内の窓どうしのやり取りで結果を受け取るだけで、受け取るのは自分で開いたツールからのものに限ります。

                        共有リンクはブラウザの中で作られます。中身は各項目の評価、主な数値、見つかった問題、各ツール自身の結果リンクです。IP アドレスは各ツールの初期設定どおり一部を伏せるので、完全な形では入りません。1ms.dog で短縮リンクを作ると、短縮リンクとプレビュー画像は短縮リンクのサービスに保存されます。詳しくは共有画面に書いてあります。

                        IPQuality や NodeQuality などのスクリプトとの違いは？

                        これらのスクリプトはサーバーに SSH でログインして動かすので、サーバー自身の IP しか調べられません。ネットワーク透視はブラウザで動くため、いま実際に使っている回線を調べます。自宅の光回線、モバイル回線、プロキシや VPN などです。タイムゾーン、言語、WebRTC など、サーバー側のスクリプトでは見えないことも確認できます。結果はリンクと画像カードで共有できます。
