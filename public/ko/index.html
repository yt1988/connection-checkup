                        도움말

                        네트워크 투시은 무엇을 하나요?

                        이 페이지 안에서 1ms.dog의 도구 8개를 차례로 실행하고 결과를 보고서 하나로 합칩니다: 당신은 누구(웹사이트가 알아낼 수 있는 것), IP 품질 테스트, 출구 IP 돋보기(사이트마다 보이는 출구), IPv6 테스트, DNS 테스트, 스트리밍/AI 언락 체크, 1ms.dog의 서비스 지연 테스트, 인터넷 속도 측정.

                        각 도구는 자기 프레임에서 실행되어 진행 상황과 결과를 직접 보여 주고 숫자를 이 페이지에 넘깁니다. 두 번 측정하거나 단순화하지 않습니다. 여기의 숫자는 도구가 직접 표시하는 숫자입니다.

                        왜 3단계로 약 90초가 걸리나요?

                        지연과 DNS 측정은 다른 트래픽에 민감해서 대역폭 테스트는 맨 마지막에 단독으로 실행합니다. 1단계는 신원, IP, 출구, IPv6, DNS를 동시에, 2단계는 언락과 서비스 지연, 3단계는 속도입니다.

                        각 단계는 도구가 모두 응답하거나 90초가 지날 때까지 기다립니다. 제때 응답하지 않은 도구는 '미완료'로 표시되고 등급에서 제외됩니다.

                        등급은 어떻게 계산하나요?

                        다섯 섹션을 각각 A+부터 F까지 평가합니다: IP 품질 25%, 언락 20%, 속도 20%, 신원과 개인정보 20%, 연결성(IPv6, DNS, 서비스 지연) 15%. 종합 등급은 완료된 섹션의 가중 평균이며, 완료되지 않은 섹션은 제외하고 보고서에 표시합니다.

                        자체 등급을 내는 도구(IP 품질, IPv6)는 그 등급을 그대로 쓰고, 나머지는 사실로 점수를 매깁니다: 사용 가능한 서비스 수, 다운로드 속도와 부하 시 지연 증가, 유출이나 불일치 여부, DNS와 주요 서비스의 속도.

                        '종합 소견'이란 무엇인가요?

                        결과를 나란히 놓아야 보이는 결론이 있습니다: 데이터센터 IP와 다른 나라의 시스템 시간대(불완전한 위장), 제한 지역 출구에서 AI 서비스 전부 차단, AI와 스트리밍이 다른 나라를 거치는 분기 라우팅, DNS와 출구의 지역 불일치, 다운로드 중 지연 급증. 이런 것들을 보고서 맨 위에 둡니다.

                        내 데이터가 브라우저 밖으로 나가나요?

                        각 도구는 평소처럼 브라우저 안에서 실행됩니다. 이 페이지는 브라우저의 프레임 간 메시지로 결과를 받을 뿐이며, 자신이 연 도구에서 온 메시지만 받습니다. 공유 링크는 브라우저에서 만들어지며 등급과 각 도구의 결과 링크만 담고 IP 주소는 담지 않습니다. 각 도구의 결과 링크는 그 도구의 개인정보 기본값을 따르며 기본적으로 주소를 제외합니다.

                        IPQuality, NodeQuality 같은 스크립트와 무엇이 다른가요?

                        그런 스크립트는 SSH로 서버에서 실행되어 서버 자신의 IP만 테스트할 수 있습니다. 네트워크 투시은 브라우저에서 실행되므로 지금 쓰고 있는 바로 그 회선을 측정합니다: 집 회선, 휴대폰, 프록시나 에어포트 노드. 서버 스크립트가 볼 수 없는 시간대, 언어, WebRTC도 봅니다. 공유할 링크와 카드도 만들어 줍니다.
