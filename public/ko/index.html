                        도움말

                        네트워크 투시는 무엇을 점검하나요?

                        이 페이지에서 1ms.dog의 도구 8개를 차례로 실행하고, 결과를 보고서 하나로 모아요. 당신은 누구(사이트가 나에 대해 알 수 있는 것), IP 품질 테스트, 출구 IP 돋보기(사이트마다 보이는 출구 IP), IPv6 테스트, DNS 테스트, 스트리밍/AI 언락 체크, 1ms.dog 메인의 서비스 지연 시간 테스트, 인터넷 속도 측정이에요.

                        각 도구는 작은 창 안에서 실행되며 자기 진행 상황과 결과를 보여 준 뒤 숫자를 이 페이지에 넘겨요. 다시 측정하거나 단순화하지 않아요. 여기 숫자는 각 도구가 보여 주는 숫자와 똑같아요.

                        왜 3단계로 나누고 90초 정도 걸리나요?

                        속도 측정은 대역폭을 꽉 채워서 지연 시간과 DNS 측정을 흐트러뜨려요. 그래서 마지막에 따로 해요. 1단계에서 신원, IP, 출구, IPv6, DNS를 함께 보고, 2단계에서 스트리밍·AI 이용 가능 여부와 지연 시간을, 3단계에서 속도를 재요.

                        단계마다 도구의 결과를 최대 90초까지 기다려요. 그때까지 결과가 오지 않은 도구는 '완료 안 됨'으로 표시하고 등급에서 빼요.

                        등급은 어떻게 매기나요?

                        보고서는 다섯 부분으로 나뉘고, 각각 A+부터 F까지 등급을 받아요. 가중치는 IP 품질 25%, 스트리밍·AI 20%, 속도 20%, 신원과 프라이버시 20%, 연결 상태(IPv6, DNS, 서비스 지연 시간) 15%예요. 종합 등급은 완료된 부분의 가중 평균이에요. 완료되지 않은 부분은 빼고, 보고서에 그렇게 적어요.

                        자체 등급을 주는 도구(IP 품질, IPv6)는 그 등급을 그대로 써요. 나머지는 측정 결과로 점수를 매겨요. 이용 가능한 서비스 수, 다운로드 속도, 회선이 붐빌 때 지연 시간이 얼마나 느는지, 유출이나 앞뒤가 안 맞는 부분이 있는지, DNS와 자주 쓰는 서비스가 얼마나 빠른지를 봐요.

                        '함께 보니 보이는 점'은 뭔가요?

                        여러 도구의 결과를 나란히 놓아야 보이는 문제예요. 예를 들어 데이터센터 IP인데 시간대가 다른 나라라서 프록시가 티 나는 경우, 출구가 제한 지역이라 AI 서비스가 전부 안 되는 경우, 분할 라우팅으로 AI와 스트리밍이 서로 다른 나라로 나가는 경우, DNS 서버와 출구 IP의 위치가 다른 경우, 다운로드 중 지연 시간이 치솟는 경우예요. 이런 내용은 보고서 맨 위에 보여 줘요.

                        내 데이터가 어딘가로 전송되나요?

                        각 도구는 따로 쓸 때와 똑같이 브라우저 안에서 실행돼요. 이 페이지는 브라우저 안의 창끼리 주고받는 메시지로 결과만 받고, 자기가 연 도구에서 온 것만 받아요.

                        공유 링크는 브라우저 안에서 만들어져요. 각 부분의 등급, 주요 수치, 발견한 문제, 각 도구의 결과 링크가 들어가요. IP 주소는 각 도구의 기본 설정대로 일부를 가리기 때문에 전체가 드러나지 않아요. 1ms.dog에서 짧은 링크를 만들면 짧은 링크와 미리보기 이미지가 링크 서비스에 저장돼요. 자세한 내용은 공유 창에 나와 있어요.

                        IPQuality, NodeQuality 같은 스크립트와 뭐가 다른가요?

                        이런 스크립트는 SSH로 서버에 접속해 실행하기 때문에 서버 자신의 IP만 확인할 수 있어요. 네트워크 투시는 브라우저에서 실행되니 지금 실제로 쓰는 연결을 점검해요. 집 인터넷, 모바일 데이터, 프록시나 VPN 모두요. 시간대, 언어, WebRTC처럼 서버 스크립트로는 볼 수 없는 것도 확인해요. 결과는 링크와 이미지 카드로 공유할 수 있어요.
